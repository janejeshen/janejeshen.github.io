This section documents practical technical challenges and exercises I have completed while developing my skills in data analysis, programming, databases, and data engineering.

## Countries of the World — Web Scraping

### Problem Statement

The goal was to collect structured information about countries from a web page and transform the extracted information into a usable dataset.

### Approach

1. Accessed the target webpage.
2. Identified the relevant HTML elements containing country information.
3. Extracted the required information using Python.
4. Cleaned and organized the scraped data.
5. Structured the results into a tabular dataset.
6. Exported the cleaned data for further analysis.

### Tools Used

`Python` `Web Scraping` `BeautifulSoup` `Pandas`

### Key Lessons Learned

- How web pages are structured using HTML.
- How to locate and extract information from HTML elements.
- How to clean scraped data before analysis.
- How to transform unstructured web information into structured datasets.

[View Challenge on GitHub](https://github.com/janejeshen/countries-of-the-world-web-scraper)

## SQL Challenge

### Problem Statement

A collection of SQL problems designed to strengthen practical SQL skills through data querying, filtering, aggregation, joins, and analytical problem-solving.

### Approach

For each challenge, I:

- Interpreted the business or analytical question.
- Identified the relevant tables and columns.
- Built SQL queries to retrieve the required information.
- Used filtering, aggregation, joins, subqueries, and other SQL techniques where appropriate.
- Reviewed the results to ensure they answered the original question.

### Tools Used

`SQL` `PostgreSQL` `SQL Server`

### Key Lessons Learned

- Improved my ability to translate analytical questions into SQL queries.
- Strengthened my understanding of joins and aggregations.
- Practiced writing clearer and more efficient SQL.
- Improved my problem-solving approach when working with relational data.
